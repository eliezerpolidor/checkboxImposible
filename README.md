## 🧠 Conceptos Técnicos Aplicados
En este repositorio demuestro el dominio de técnicas de Frontend que van más allá del diseño básico:

1. **Checkbox Hack:** Uso de la pseudo-clase `:checked` para controlar estados de la interfaz sin necesidad de JavaScript.
2. **Keyframe Orchestration:** Sincronización precisa de múltiples animaciones (`punch`, `reset-color`, `reset-thumb`) para crear una interacción coherente.
3. **Selectores de Hermanos (`~` y `+`):** Manipulación de elementos adyacentes basada en el estado de un input.
4. **Cubic-bezier:** Implementación de curvas de tiempo personalizadas para lograr un movimiento orgánico y con "personalidad" en la mano.
5. **Responsive Design:** Uso de Media Queries para asegurar que la experiencia sea fluida en dispositivos móviles.
